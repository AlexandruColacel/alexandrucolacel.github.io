## 🚀 Proyectos Destacados

### 🎮 [DriverControllerForMe](ENLACE_A_TU_REPO_DRIVER)
*Middleware de entrada en User-Mode para revivir hardware moderno en juegos legacy.*

* **El Problema:** Motores antiguos (ej: Gothic II) no reconocen mandos modernos vía XInput.
* **La Solución:** Desarrollé un driver en **Python** usando `ctypes` para realizar **API Hooking** e interceptar llamadas al sistema, inyectando inputs mapeados en memoria.
* **Tech Stack:** Python, WinAPI, Memory Mapping.

### 🔄 [GameSaveSync-gRPC](ENLACE_A_TU_REPO_GAMESAVESYNC)
*Sistema distribuido de alta eficiencia para sincronización de archivos binarios.*

* **Descripción:** Solución de ingeniería para sincronizar partidas guardadas (archivos binarios grandes) con latencia mínima, superando las limitaciones de REST mediante **gRPC sobre HTTP/2**.
* **Arquitectura:** Implementa **Streaming Bidireccional** con Protocol Buffers para evitar cuellos de botella en memoria.
* **Tech Stack:** .NET 9 (C#), Python Client, gRPC, Protobuf, Docker.
