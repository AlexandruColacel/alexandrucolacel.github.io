## 🚀 Proyectos

### 🎮 [DriverControllerForMe](https://github.com/alexandrucolacel/DriverControllerForMe)
> **Middleware de entrada en User-Mode para revivir hardware moderno en juegos legacy.**

* **El Problema:** Motores antiguos (ej: Gothic II) no reconocen mandos modernos vía XInput.
* **La Solución:** Desarrollé un driver en **Python** usando `ctypes` para realizar **API Hooking** e interceptar llamadas al sistema, inyectando inputs mapeados en memoria.
* **Tech Stack:** Python, WinAPI, Memory Mapping.

### 🔄 [GameSaveSync-gRPC](https://github.com/alexandrucolacel/GameSaveSync-gRPC)
> **Sistema distribuido de alta eficiencia para sincronización de archivos binarios.**

* **Arquitectura:** Cliente-Servidor con **Streaming Bidireccional** sobre **gRPC (HTTP/2)**.
* **Eficiencia:** Usa Protocol Buffers para minimizar el ancho de banda y escritura asíncrona en disco.
* **Tech Stack:** .NET 9 (C#), Python Client, Docker, RabbitMQ.
